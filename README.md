# nhplot_for_bioinformatics

科研绘图分享资料。每期三张、全栏目连续编号；按图名查看数据、现有成图、R代码及Agent提示词。

## 目录

- `data/`：绘图输入、已有统计结果或模拟数据。
- `figure/`：现有 PNG、PDF、SVG 原样文件。
- `script/`：R模板、共享模块和按仓库根目录设置的数据配置。
- `prompt_to_agent/`：每图说明与可交给Agent读取的提示词。

## 使用

将仓库交给你的Agent，让它先阅读 `prompt_to_agent/` 下对应图名的提示词和说明，再检查依赖、字段映射、数据路径与共享模块加载，在新目录中完成适配与复现。现有图片和数据保持只读。脚本保留原有实现，本次没有重新执行，也不承诺搬移后无需适配即可运行。

## 示例与来源

1. 配对箱线轨迹：Gapminder国家预期寿命示例，420条观测、140个国家、三个年份；输入仅将现有观测结果重命名为标准字段。
2. 桑基与全球地图：提供的20,312条采样记录；六字段来自原有配套整理表，采样密度不表示丰度。
3. 环形细胞谱系：160名模拟供者、73亚型的演示，不是真实队列或推断的发育轨迹。

详细口径见各图说明。上游代码、数据与图片的再分发许可记录尚不完整，本仓库不额外声明统一开源许可证。

[文件对应与SHA-256清单](manifest.tsv)用于核对本地资料与仓库文件；不包含系统隐藏文件或本地账号配置。

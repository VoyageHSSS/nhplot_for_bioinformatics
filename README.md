# nhplot_for_bioinformatics

科研绘图分享资料。每期三张、全栏目连续编号；按图名查看数据、现有成图、R代码及Agent提示词。

## 目录

- `data/`：绘图输入、已有统计结果或模拟数据。
- `figure/`：现有 PNG、PDF、SVG 原样文件。
- `script/`：R模板、共享模块和按仓库根目录设置的数据配置。
- `prompt_to_agent/`：每图说明与可交给Agent读取的提示词。

## 数据含义

固定种子 20261013 的模拟示例：160 名模拟供者、73 个亚型、五大谱系及 RNA/ATAC 两种模拟测量。年龄/性别关联共292项系数检验一起BH校正。树表示显式分类层级，不是推断的发育轨迹；不是原论文队列、原始组学或真实研究发现。

依赖：ggplot2、jsonlite、ragg、svglite、showtext、sysfonts、systemfonts；另需共享颜色模块。本期只整理共享资料，没有重新运行R、安装依赖或测试搬移后的执行。配置里的data_path以本图文件夹为工作目录；运行前由Agent检查脚本相对路径与模块加载。共享颜色模块可通过PLOT_NH_COLOR_MODULE指定；第一例还需在同一R进程加载提供的格式模块。已有figure只读，新结果另存。
